# Security

Please report security problems privately, not in a public issue: open the repository's Security tab and choose
"Report a vulnerability". Say what you found, how to reproduce it, and which version you use (`chatwire version`).
You will get an answer as soon as possible, and credit in the release notes unless you prefer otherwise.

Worth reporting:

- Anything that lets a message, a file or another program make Chatwire read, send or reveal something the user did
  not ask for
- Ways around the file folder limits (`CHATWIRE_FILES`) or read-only mode (`CHATWIRE_READ_ONLY`)
- Problems with the linked device's keys or the local message store
- Problems in the installers or in `chatwire update`

Not in scope: WhatsApp's own apps and servers (report those to Meta), and the risk that WhatsApp restricts accounts
that use unofficial clients.
